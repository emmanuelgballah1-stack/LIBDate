# LIBDate Prototype 🇱🇷

A front-end prototype for LIBDate — "Where Liberia Connects."

## Included
- Liberia-themed red, white and blue UI
- Subtle Liberia-inspired background treatment
- Onboarding flow
- Discover/profile cards
- Mutual "Connection" concept instead of "Match"
- Compatibility percentage
- Connection requests
- Connections screen
- Messages and working chat prototype
- Conversation starter
- Profile screen
- Responsive mobile-first layout

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open the terminal in the project folder.
4. Run:
   npm install
   npm run dev
5. Open the local URL Vite gives you.
